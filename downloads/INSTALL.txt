PartTrace private preview

WINDOWS: Download and run the Preview-Setup.exe on the computer that will run PartTrace.
It includes Node and all required application files. The Windows installer is unsigned:
this is an internal preview, not a signed customer release. Follow your Windows policy.
Setup starts the service, prepares networking and opens PartTrace in your browser.

ANDROID: Prefer scanning Add a device in your workshop. The included Android APK is the
existing release-signed app; the Windows installation also serves it over your local network.

SHA256SUMS.txt lists the files' checksums. Keep normal backups of existing workshop data.
